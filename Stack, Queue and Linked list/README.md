# 🧱 Fundamental Data Structures – Data Structures Project

## 📌 Project Overview
This project focuses on the implementation of key **data structures**: **Stack**, **Queue**, and **Linked List**.  
These structures are foundational in computer science and are widely used in **algorithms**, **system design**, and **real-world applications**.

Each data structure is implemented with clean code and includes core operations and test examples.

---

## 🔧 Key Features

### 📚 Stack (LIFO)
A **Last-In, First-Out** structure where the most recently added item is removed first.

- `push(x)` – Add an element to the top
- `pop()` – Remove the top element
- `peek()` – View the top element without removing it

---

### 🎯 Queue (FIFO)
A **First-In, First-Out** structure where the earliest added element is removed first.

- `enqueue(x)` – Add an element to the rear
- `dequeue()` – Remove the front element

---

### 🔗 Linked List
A linear structure made up of **nodes**, each pointing to the next node.

- `insert(position, value)` – Add a node at a given position
- `delete(position)` – Remove a node from a given position
- `search(value)` – Find a node with the specified value
