# 🧱 Data Structures – University of Tehran Projects

This repository contains practical implementations of fundamental **data structures** as part of the **Data Structures & Algorithms** course at the **University of Tehran**.  
Each folder covers a specific category of data structures along with example algorithms, core operations, and performance analysis.

---

## 📁 Project Structure

| Folder                           | Description                                                                 |
|----------------------------------|-----------------------------------------------------------------------------|
| 🔁 **Stack, Queue and Linked List** | Basic linear data structures and their key operations (`push`, `pop`, `enqueue`, `insert`, etc.) |
| 🧠 **Time Complexity and Recursion** | Recursive algorithms with time complexity analysis using Big-O notation     |
| 🌐 **Graph**                      | Graph traversals (BFS, DFS), shortest path algorithms (Dijkstra, Bellman-Ford), and MSTs |
| 🌳 **Tree and Heap**              | Implementations of Binary Search Tree and Heap (Min/Max), including `insert`, `delete`, and `heapify` |

---

## 🧠 Concepts Covered

- Linear data structures: `Stack`, `Queue`, `Linked List`
- Recursive thinking and complexity analysis
- Non-linear structures: `Graph`, `Tree`, `Heap`
- Algorithmic thinking and problem-solving with Python
