# 🔁 Recursion & Time Complexity – Algorithm Analysis Project

## 📌 Project Overview
This project focuses on implementing and analyzing algorithms that utilize **recursion** to solve problems by breaking them down into smaller subproblems.  
Understanding recursion is foundational in computer science, especially in **divide-and-conquer** strategies.  
Each algorithm in this project is paired with an analysis of its **time complexity** using **Big-O notation**.

---

## 📚 Key Concepts

- 🌀 **Recursion**: A process where a function calls itself to solve simpler instances of a problem.
- ⏱ **Time Complexity**: The computational cost of an algorithm as a function of input size (`n`), measured using Big-O notation.

---

## 🧠 Algorithms Implemented

### 1. 🧮 Factorial (Recursive)
- Description: Computes the factorial of a number using recursion.
- Time Complexity: **O(n)**

### 2. 🐚 Fibonacci Sequence (Recursive)
- Description: Calculates the `n`th Fibonacci number recursively.
- Time Complexity: **O(2ⁿ)** – due to repeated subproblem computations.

### 3. 📦 Merge Sort
- Description: Recursive divide-and-conquer sorting algorithm.
- Time Complexity: **O(n log n)** – efficient and stable sort.

### 4. 🗼 Tower of Hanoi
- Description: Moves `n` disks between three pegs following classic rules.
- Time Complexity: **O(2ⁿ)** – exponential due to number of required moves.
