# 🌐 Graph Algorithms – Algorithm Design Project

## 📌 Project Overview
This project focuses on the implementation and analysis of classic **Graph Algorithms**, which are widely used in computer science to solve problems related to **networking**, **routing**, **connectivity**, and **optimization**.

Graphs are represented using **adjacency lists** or **adjacency matrices**, and both **traversal** and **optimization** algorithms are implemented in Python.

---

## 🔧 Key Features

### 🔗 Graph Representation
- **Adjacency List** – Efficient for sparse graphs
- **Adjacency Matrix** – Useful for dense graphs or when quick edge lookup is required

### 🔍 Traversal Algorithms
- **BFS (Breadth-First Search)** – Explores the graph level by level
- **DFS (Depth-First Search)** – Explores the graph depth-wise using recursion or stack

### 🧭 Shortest Path Algorithms
- **Dijkstra’s Algorithm** – Finds shortest path in weighted graphs (non-negative weights)
- **Bellman-Ford Algorithm** – Handles graphs with negative edge weights
- **Floyd-Warshall Algorithm** – Computes all-pairs shortest paths

### 🌲 Minimum Spanning Tree (MST)
- **Kruskal’s Algorithm** – Greedy approach using disjoint sets
- **Prim’s Algorithm** – Greedy method using priority queue or array
