# 🌲 Tree & Heap Data Structures – Data Structures Project

## 📌 Project Overview
This project involves the implementation and analysis of fundamental **Tree** and **Heap** data structures.  
These structures are foundational in computer science and are widely used in algorithms, memory management, sorting, and searching systems.

The project includes full implementation of **Binary Search Trees (BST)** and **Heaps**, along with key operations and analysis of time complexity.

---

## 🔧 Key Features

### 🌳 Binary Tree & Binary Search Tree (BST)
- A hierarchical structure where each node has at most two children
- In a **BST**, left children < parent < right children

### 🔍 Heap
- A complete binary tree that satisfies the **heap property**:
  - **Max-Heap**: Parent nodes are greater than or equal to children
  - **Min-Heap**: Parent nodes are less than or equal to children

---

## 🧠 Data Structures Implemented

### ✅ Binary Search Tree (BST)
- `insert(value)` – Adds a new element while preserving BST properties
- `search(value)` – Finds whether a value exists in the tree
- `delete(value)` – Removes a node and restructures the tree accordingly

### ✅ Heap
- `insert(value)` – Inserts a new element and maintains heap property
- `extract_max()` or `extract_min()` – Removes and returns root element
- `heapify()` – Re-establishes heap condition after updates
